# Car Market Trends Analysis with CarDekho Data

## Objective
Analyze used-car market trends and understand how manufacturing year, fuel type, seller type,
transmission, kilometres driven and present price relate to selling price.

## Dataset
- Records analyzed after duplicate removal: 299
- Columns: Car_Name, Year, Selling_Price, Present_Price, Kms_Driven,
  Fuel_Type, Seller_Type, Transmission, Owner

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Workflow
1. Load the dataset.
2. Check missing values and duplicate records.
3. Remove duplicates.
4. Perform exploratory data analysis.
5. Create visualizations.
6. Summarize market insights.

## Key Findings
- Most common fuel type: Petrol.
- Most common transmission: Manual.
- Most common seller type: Dealer.
- Average selling price: 4.59 lakhs.
- Median selling price: 3.51 lakhs.
- Cars in the dataset range from 2003 to 2018.
- Highest observed selling price: 35.00 lakhs.
